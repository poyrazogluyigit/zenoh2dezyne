# Zenoh-to-Dezyne Model Translator 

This project aims to implement a static analysis based model extractor and translator for publish/subscribe applications implemented with Zenoh C++. The project also provides example systems for testing and benchmarking. 

The repository currently contains examples for:
- The dining philosophers problem (naive solution)
- A simplification of the PGM (Pragmatic General Multicast) protocol

The examples are inspired from the [BEEM Benchmark Suite](https://github.com/plug-obp/beem-benchmark).
