## Phase 3 — Topology Graph (Publisher ↔ Subscriber Matching)

```scala
// Q21: Build edge list: (publisher_file, key_expr, subscriber_file)
// Step 1: Collect all publisher key expressions per file
val pubs = cpg.call.name("declare_publisher")
  .map(c => (c.file.name.head, c.argument(1).code.stripPrefix("\"").stripSuffix("\"")))
  .l

// Step 2: Collect all subscriber key expressions per file  
val subs = cpg.call.name("declare_subscriber")
  .map(c => (c.file.name.head, c.argument(1).code.stripPrefix("\"").stripSuffix("\"")))
  .l

// Step 3: Match — literal equality on key expression
val edges = for {
  (pubFile, pubKey) <- pubs
  (subFile, subKey) <- subs
  if pubKey == subKey && pubFile != subFile
} yield Map("from" -> pubFile, "keyExpr" -> pubKey, "to" -> subFile)

// Q22: Fan-out detection — count subscribers per (key, publisher)
edges.groupBy(e => (e("keyExpr"), e("from")))
  .mapValues(_.map(_("to")).distinct.size)
  .filter(_._2 > 1)
```

## Phase 9 — Inter-Callback Data Flow (Shared State Dependencies)

```scala
// Q54: Data flow from assignment in callback A to condition-read in callback B
// Example: TX_TRAIL written in nak_callback, read in main
def source54 = cpg.method.name("nak_callback")
  .ast.isCall.name("<operator>.assignment")
  .argument(1).isIdentifier.name("TX_TRAIL")

def sink54 = cpg.method.name("main")
  .ast.isControlStructure.condition
  .ast.isIdentifier.name("TX_TRAIL")

sink54.reachableByFlows(source54).p

// Q55: Generic cross-callback data flow for all shared state variables
// For each state var: find all writing callbacks and reading callbacks
cpg.identifier
  .map(i => (i.name, i.method.name, i.file.name.head))
  .l
  .groupBy(_._1)
  .filter { case (_, refs) => refs.map(_._2).distinct.size > 1 }
  .mapValues(_.map(r => (r._2, r._3)).distinct)

// Q56: For a specific state variable, trace all writes → reads across methods
def source56 = cpg.call.name("<operator>.assignment")
  .where(_.argument(1).code("LAST_RECEIVED"))
def sink56 = cpg.identifier.name("LAST_RECEIVED")
  .where(_.inCall.nameNot("<operator>.assignment").argument(1))
sink56.reachableByFlows(source56).p

// Q57: Guards — conditions that reference state variables in callbacks
cpg.method.parameter.typeFullName(".*Sample.*").method
  .ast.isControlStructure.controlStructureType("IF")
  .condition
  .ast.isIdentifier
  .map(i => Map(
    "callback" -> i.method.name,
    "guardVar" -> i.name,
    "inFile"   -> i.file.name.head
  ))
  .dedup
  .l

// Q58: For each state variable, which callbacks WRITE it and which READ it in guards
val allCallbacks = cpg.method.parameter.typeFullName(".*Sample.*").method.name.l

cpg.identifier
  .where(_.method.name(allCallbacks.mkString("|")))
  .map(i => (i.name, i.method.name))
  .l
  .distinct
  .groupBy(_._1)

// Q59: Full dependency graph: callback A writes var X → callback B guards on X
val writeMap = cpg.call.name("<operator>.assignment")
  .where(_.method.parameter.typeFullName(".*Sample.*"))
  .map(a => (a.argument(1).code, a.method.name))
  .l.distinct

val guardMap = cpg.method.parameter.typeFullName(".*Sample.*").method
  .ast.isControlStructure.condition
  .ast.isIdentifier
  .map(i => (i.name, i.method.name))
  .l.distinct

for {
  (wvar, wmethod) <- writeMap
  (gvar, gmethod) <- guardMap
  if wvar == gvar && wmethod != gmethod
} yield Map("writer" -> wmethod, "var" -> wvar, "guarder" -> gmethod)
```

**Notes on C++ / Joern Specifics:**

- Joern's c2cpg frontend models C++ member calls as `call` nodes where `argument(0)` is the receiver object. For `publisher.put(payload)`, `argument(0).code` gives `publisher` and `argument(1).code` gives `payload`.
- Operators like `==`, `<`, `>`, `&&`, `=`, `++` appear as calls named `<operator>.equals`, `<operator>.lessThan`, `<operator>.greaterThan`, `<operator>.logicalAnd`, `<operator>.assignment`, `<operator>.postIncrement`, etc.
- c2cpg may require zenoh headers in the include path for full type resolution. Use `--include /path/to/zenoh-cpp/include` or a `compile_commands.json` via `--compilation-database`.
- `run.ossdataflow` must be called before any `reachableBy` / `reachableByFlows` queries.
- Regex patterns in `.name("...")` use Java regex (e.g., `.*` for wildcard, `|` for alternation).
